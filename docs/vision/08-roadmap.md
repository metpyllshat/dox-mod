# 08. Порядок работ

Оценки — в «днях» по 6–7 часов работы с проверкой в игре. Всего около 23 дней, но играть станет интереснее уже после первого спринта.

## Принцип порядка

Сначала то, что **меняет ощущение вечера за один вечер**. Потом то, что добавляет глубину. В конце — то, что нужно только для стрима и долгой жизни.

Каждый спринт должен заканчиваться играбельным состоянием: если после спринта нельзя позвать людей и сыграть — спринт спланирован неправильно.

---

## Спринт 0. «Слышно» — 2 дня

**Цель:** игрок впервые чувствует, что эфир — это опасно.

| Задача | Объём |
|---|---|
| Событие шума как объект (`Noise`), таблица действий | 0.5 дня |
| Индикатор эфира в сайдбаре + «тебя слышно» | 0.3 |
| Сайдбар по новой схеме (15 строк) | 0.3 |
| Тариф на повторный TRACE | 0.2 |
| Голос канала: текст в чат на 7 событий | 0.4 |
| Лог шума для админа (`/minigame noise`) | 0.3 |

**Проверка:** после катки игроки говорят «я боялся жать TRACE». Значит, получилось.

---

## Спринт 1. «Луч» — 3 дня

**Цель:** разведка становится задачей, а не кнопкой.

| Задача | Объём |
|---|---|
| Пеленг: из TRACE убрать точку, выдать луч | 0.7 |
| Модель луча (источник, угол, α, возраст) | 0.4 |
| Пересечение лучей и расчёт пятна | 0.6 |
| Отрисовка на телефоне и ноутбуке | 0.8 |
| Второй прибор: тарелка даёт второй луч | 0.5 |
| Подсказка «нужен второй луч» в интерфейсе | 0.3 |

**Проверка:** два игрока в голосовом чате обсуждают, откуда взять второй луч. Это уже другая игра.

**Зависимость:** без спринта 0 лучи будут в вакууме — сначала шум.

## Что резать (и не жалеть)

| Соблазн | Почему нет |
|---|---|
| **Ядерка в луте** | обесценивает катку; остаётся крафтовым проектом на 4–8 часов |
| **Классы с прокачкой** | снежок и потеря свободы; роли через снаряжение лучше |
| **Миникарта с рельефом** | убивает разведку и разговоры |
| **Клиентский HUD** | требует мода на клиенте у всех — ставим только сайдбар и боссбар |
| **10 типов POI сразу** | четыре типа дадут 80% ощущения |
| **Подслушивание голоса по умолчанию** | конфликты вне игры; только опцией |
| **Второй ресурс** | одна валюта читается, две — бухгалтерия |
| **Урон по таймеру в финале** | слепота страшнее и честнее |

## Метрики: как понять, что стало лучше

Не «нравится/не нравится», а числа с вечера.

| Метрика | Как мерить | Цель |
|---|---|---|
| Время до первого контакта | лог | 8–15 минут |
| Доля живых к финалу | лог | 50–70% |
| Минуты в спектаторе на игрока | лог | < 8 |
| Открытий телефона за катку | лог | 35–60 |
| Выполненных контрактов на отряд | лог | 3–5 |
| Смертей на игрока | лог | 2–4 |
| «Было скучно» в опросе | голосом | 0 из 8 |
| «Хочу ещё катку» | голосом | ≥ 6 из 8 |

Первые шесть можно собрать без отдельной телеметрии — из существующих событий в `Minigame`.

## Риски

| Риск | Что делаем |
|---|---|
| **Телефон слепит** | панель на половину экрана, звук не глохнет, тревога при контакте |
| **Новичок теряется** | три задачи, полигон, голос канала |
| **Мёртвая середина** | контракты, вышки, аирдропы, события |
| **Просадка TPS** | синк 4 раза в секунду, кэш, никаких пакетов каждый тик |
| **90 минут тяжело** | швы, пересменка задач, возможность выйти и вернуться (заряд) |
| **Снежок** | досье лидера, отчаянный контракт, нейтральные вышки |
| **Ссоры из-за подслушивания** | выключено по умолчанию, уведомление после катки |
| **Слишком сложно для вечера** | правило «объясняется за 15 секунд», тест на живых людях после каждого спринта |

## Чек-лист первого вечера после спринта 0–2

1. Минимум 8 человек, лучше 12.
2. Все в голосовом чате — без него игра не работает.
3. Карта 1000–1500, 4 отряда (для теста) и 2500 на полноценный вечер.
4. Один админ, который не играет и записывает тайминги.
5. После катки — пять минут разбора: что было непонятно, что скучно, что запомнилось.
6. Один вопрос, на который нужен ответ: «что ты делал на 45-й минуте?»

Если на шестой вопрос половина отвечает «сидел на базе» — следующий спринт не тот, который в плане.
