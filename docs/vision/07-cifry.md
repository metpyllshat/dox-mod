## Что это значит по темпу

За 90 минут средний игрок должен:

| Событие | Сколько раз | Проверка |
|---|---:|---|
| Открыть телефон | 35–60 | каждые 1.5–2.5 минуты |
| Сделать TRACE | 8–12 | больше — дорого по тарифу |
| Услышать чужой шум | 20–30 | эфир живой |
| Встретить врага | 4–6 | не «тир», но и не «пусто» |
| Умереть | 2–4 | с зарядами это не приговор |
| Выполнить контракт | 3–5 | всегда есть дело |
| Подержать вышку | 1–2 | карта контроля двигается |

Если после первого вечера какая-то из этих цифр вдвое хуже — правим её, а не всю систему.
