# Что проверить руками

Список для теста: каждый пункт — то, что нельзя проверить линтером. Проходим по порядку, начиная с матча: если база не встала, остальное смотреть бессмысленно.

Открыть панель: `/bc admin` (нужен второй уровень прав). В панели есть та же памятка во вкладке `ЧЕК-ЛИСТ`.

## 1. Запуск

- [ ] Игра стартует, в `latest.log` нет строк с `BlackChannel` и `ERROR`.
- [ ] Главное меню: фон с заводом и тарелкой, крупный заголовок, справа сводка канала, слева бегущий терминал.
- [ ] «Одиночная игра», «Сетевая игра», «Настройки», «Моды», «Выйти» — каждая кнопка открывает свой экран.
- [ ] Выход из мира возвращает наше меню, а не ванильное.

## 2. Матч и базы

- [ ] В панели: `ЦЕНТР ЗДЕСЬ`, размер `1000`, `СТАРТ`.
- [ ] Базы встали на суше. В логе **нет** строк `база ставится как есть` и `сухой площадки рядом ... нет`.
- [ ] Если база съехала — в логе будет `база съехала на N блоков на сушу X Y Z`, и это норма.
- [ ] Бункер: люк на поверхности, лестница вниз, маяк в зале 5×5.
- [ ] Щит маяка первые минуты (в конфиге `beaconShieldSeconds`).
- [ ] Стартовый набор: кровать, каменные инструменты, хлеб. **Телефона и батарейки нет.**

## 3. Телефон

Открывается ПКМ по телефону. Панель `248×228`, ничего не должно наезжать.

- [ ] Статус-бар: четыре столбика сети, часы, батарея с процентом.
- [ ] Шапка: вкладка, крипта справа, позывной и отряд слева, состояние эфира справа.
- [ ] Полоса `ШУМ` на 14 столбиков и подпись `тихо / шёпот / СЛЫШНО / СЛЫШНО ДАЛЕКО`.
- [ ] Кнопок `DARK`, `LOCAL`, `DM` больше нет — чат один.
- [ ] `ЭФИР`: Enter отправляет, `@позывной текст` уходит в личку, сообщения видны списком, длинные режутся, а не наезжают на разделитель.
- [ ] `КАРТА`: сетка, стрелка игрока, блипы по типам, лучи пеленгов, справа список отметок.
- [ ] `СЕТЬ`: авиарежим, DND, радар HUD, ГАЙД, сжигание SIM; ниже строки аплинк / VPN / IDS / закалка / спутник.
- [ ] `РЫНОК`: три подвкладки. Витрина — 12 лотов, выбор и покупка. Доска — лоты игроков, у разведданных координаты замаскированы. Аукцион.
- [ ] Наведение на лот даёт подсказку с ценой и продавцом.

## 4. Ноутбук

- [ ] Три вкладки: `СЛЕД`, `СУМКА`, `ТОРГ`.
- [ ] `TRACE` печатает позывной в поле и выдаёт результат под кнопками.
- [ ] `WIPE` в два нажатия, второе подтверждает.
- [ ] `INTEL`: строки не наезжают, устаревшая точка помечена.
- [ ] `СУМКА`: 36 слотов + хотбар, кнопка снимка.
- [ ] `ТОРГ`: слот, ползунок цены, продажа предмета и разведданных.

## 5. Механики

- [ ] Шум: скажите в чат несколько раз — полоса растёт, потом сама гаснет (−2 каждые 20 тиков).
- [ ] Шум: панель → `ШУМ 100`, затем TRACE по вам с другого клиента — луч должен быть уже.
- [ ] Пеленг: два луча дают точку с погрешностью.
- [ ] ЭМИ: панель → `ЭМИ`, телефон гаснет, меню закрывается, стойки перезагружаются, шум обнуляется.
- [ ] Флуд: панель → `ФЛУД`, экран забивается картинками.
- [ ] Рынок: покупка списывает крипту, лот появляется в инвентаре.
- [ ] Дедлайн: панель → `ФИНАЛ ЧЕРЕЗ 60С`, боссбар переключается на финал.
- [ ] Конец матча: победитель в чате, маяки, бункеры и схроны убраны, мир без дыр.

## 6. Что делать, если сломалось

1. Скопировать из `latest.log` строки вокруг ошибки — по ним видно, какой класс и какая строка.
2. Если ошибка в момент старта матча — приложить вывод `/bc status` и строки `BlackChannel: база ...`.
3. Если что-то не рисуется — указать вкладку и масштаб интерфейса (в настройках игры), на 1× и 3× вид разный.

## 7. Контракты, звук и диктор (раунд 2026-11-02)

- [ ] Старт матча: в телефоне вкладка `ЗАДАЧИ` (пятая), в ней три карточки, у каждой текст, полоска, `N/M · мм:сс` и награда `+N`.
- [ ] Диктор на старте: голос «Канал открыт», текст в чате остался прежним.
- [ ] TRACE с результатом двигает прогресс `TRACE`-задания отряда. Без результата (нет сигнала) — не двигает.
- [ ] Взлом стойки чужого отряда (`ВЗЛОМ`, владелец другой) закрывает `HACK`. Свою стойку взламывать нельзя.
- [ ] Захват вышки и два убийства врагов закрывают `TOWER` и `KILL`, награда уходит всему отряду в кошелёк (`#N`).
- [ ] `DELIVER`: в инвентаре есть предмет из списка (эксплойт, нулевой день, фальшивый контракт, образец). Задание появилось только для предметов, которые у отряда уже есть. Кнопка СДАТЬ забирает предметы у членов отряда онлайн.
- [ ] Отстающий по очкам получает отчаянный контракт (красный заголовок `ОТЧАЯННЫЙ`, награда ×2), один раз за катку.
- [ ] Срок: задание, которое не выполнено за `contractMinutes`, сгорает с сообщением в чате, новое приходит сразу.
- [ ] Звуки: клик по кнопкам телефона и ноутбука, пинг при новом пеленге, гул при глушении.
- [ ] Победа: если отряд весь вышел с сервера, соперник не выигрывает мгновенно, пока игроки не вернулись или не погибли.
- [ ] Ноутбук: TRACE с позывным сразу отправляет запрос (мини-игры взлома нет), Enter на вкладке TRACE делает то же.
- [ ] Диктор на шторме, тишине, сводке, аирдропе, узле, захвате вышки и выбытии отряда — каждое событие даёт голос и строку в чате.
- [ ] Вторая катка подряд в том же мире: вышки снова стоят все (`towerCount`), старые блоки прошлой катки не остаются.
- [ ] Суперфлэт: вышки стоят (раньше порог высоты отсекал поверхность на y=-61).
- [ ] Вышки стоят по кругу, не кучно: соседние разнесены, на карте 512+ — все 6.
- [ ] Кнопка КАМЕРА/СКАН в СЕТИ активна только при своей вышке (не чужой), не выведенной ЭМИ. Камера («ОБЗОР»): 20 с точка облетает вышку по кругу на высоте верхушки, мышью смотришь сам; после окончания возвращает в прежний режим и место.
- [ ] Вышки: при `towerCount` = 6 на карте стоит 6 вышек (допустимо меньше только если места нет вовсе, в логе будет предупреждение). Вышки не лепятся друг к другу.
- [ ] После конца катки (по победе или по таймауту) вышки, маяки и сундуки на месте вышек убраны, без команды `stop`.
- [ ] Победа по очкам по таймауту финала (не последний отряд): объявлен отряд с наибольшим счётом.
- [ ] TRACE-контракт засчитывается только за пеленг с результатом (координаты), пеленг «луч» без результата не даёт прогресса.
- [ ] Радар телефона: точка возрождения в кровати подписана «кровать» (не сырым ключом `blackchannel.blip.bed`), цвет зелёный.
- [ ] Удар ЭМИ по маяку: вышки глохнут; если сбой, в логе `EMP towers pulse failed`, а удар всё равно проходит.
- [ ] Обзор вышки: при нажатии КАМЕРА игрок переходит в наблюдатели, точка облетает вышку (радиус 14 блоков), через 20 с возвращается в свой режим и на своё место. Для творческого режима возврат тоже в творческий.
- [ ] Обзор вышки: отказ (нет своей вышки / мало крипты / уже идёт обзор) пишется в чат, а не только в строке над хотбаром.
- [ ] Обзор вышки и выход из игры: если отключиться во время обзора, при входе игрок возвращается в свой режим и на своё место.
- [ ] Итоги катки в чат: после конца катки каждый игрок отряда видит строку с убийствами, смертями, пеленгами, вышками, крипто с заданий и титулом.
- [ ] Статистика сбрасывается при старте новой катки (в итогах только текущая катка).
- [ ] Схроны: на карте 1500x1500 в 1x1 найдено заметно больше пяти (ориентир ~18–30 на 90 минут; настройки `cachesPerTeam`, `cachesMax`).
- [ ] Сундук вышки один, в нём только ресурсы (железо, медь, золото, редстоун, лазурит, кварц, стекло), оружия нет (пул `cacheTower`, число выдач `towerLootRolls`).
- [ ] Своя вышка рядом (до `towerLinkRadius` блоков) даёт связь уровня «тарелка» и прибавляет радару `towerRadarBonus` блоков.
- [ ] Миникарта (верхний правый угол) работает при закрытом телефоне: точки игроков и узлов обновляются.
- [ ] Чат: новые задания и аирдроп в чат не пишутся (аирдроп — только в момент сброса); таймеры «Аирдроп» и «Задания» в сайдбаре; «+крипта» с вышки больше не мигает в статус-баре.
- [ ] Чужой игрок входит в зону вышки (`towerInterceptRadius`): владельцу приходит сообщение один раз за вход.
- [ ] `/minigame stats` показывает итоги текущей или последней катки.
- [ ] КАМЕРА (как дрон SBW): на вышке игрок остаётся видимым в режиме выживания и может получить урон; мышь крутит обзор; игрок не сходит с платформы (сервер возвращает его); ломать и ставить блоки во время обзора нельзя; повторное нажатие КАМЕРА выключает; смерть выключает; через 2 минуты выход сам; выход из игры во время обзора — возврат при входе.
- [ ] Ноутбук крафтится из железа, золота, редстоуна и батареи (телефон в рецепт не входит).
- [ ] Металлоискатель (крафт: железо, батарея, медь): во время катки находит ближайший схрон в `detectorRadius` (50 блоков), пишет расстояние и стрелку в actionbar; вне катки и без схронов молчит; ломается через `detectorUses`.
