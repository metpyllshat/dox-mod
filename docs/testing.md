# Что проверить руками

Список для теста: каждый пункт — то, что нельзя проверить линтером. Проходим по порядку, начиная с матча: если база не встала, остальное смотреть бессмысленно.

Открыть панель: `/bc admin` (нужен второй уровень прав). В панели есть та же памятка во вкладке `ЧЕК-ЛИСТ`.

## 1. Запуск

- [ ] Игра стартует, в `latest.log` нет строк с `BlackChannel` и `ERROR`.
- [ ] Главное меню: фон с заводом и тарелкой, крупный заголовок, справа сводка канала, слева бегущий терминал.
- [ ] «Одиночная игра», «Сетевая игра», «Настройки», «Моды», «Выйти» — каждая кнопка открывает свой экран.
- [ ] Выход из мира возвращает наше меню, а не ванильное.

## 2. Матч и базы

- [ ] В панели: `ЦЕНТР ЗДЕСЬ`, размер `1000`, `СТАРТ`.
- [ ] Базы встали на суше. В логе **нет** строк `база ставится как есть` и `сухой площадки рядом ... нет`.
- [ ] Если база съехала — в логе будет `база съехала на N блоков на сушу X Y Z`, и это норма.
- [ ] Бункер: люк на поверхности, лестница вниз, маяк в зале 5×5.
- [ ] Щит маяка первые минуты (в конфиге `beaconShieldSeconds`).
- [ ] Стартовый набор: кровать, каменные инструменты, хлеб. **Телефона и батарейки нет.**

## 3. Телефон

Открывается ПКМ по телефону. Панель `248×228`, ничего не должно наезжать.

- [ ] Статус-бар: четыре столбика сети, часы, батарея с процентом.
- [ ] Шапка: вкладка, крипта справа, позывной и отряд слева, состояние эфира справа.
- [ ] Полоса `ШУМ` на 14 столбиков и подпись `тихо / шёпот / СЛЫШНО / СЛЫШНО ДАЛЕКО`.
- [ ] Кнопок `DARK`, `LOCAL`, `DM` больше нет — чат один.
- [ ] `ЭФИР`: Enter отправляет, `@позывной текст` уходит в личку, сообщения видны списком, длинные режутся, а не наезжают на разделитель.
- [ ] `КАРТА`: сетка, стрелка игрока, блипы по типам, лучи пеленгов, справа список отметок.
- [ ] `СЕТЬ`: авиарежим, DND, радар HUD, ГАЙД, сжигание SIM; ниже строки аплинк / VPN / IDS / закалка / спутник.
- [ ] `РЫНОК`: три подвкладки. Витрина — 12 лотов, выбор и покупка. Доска — лоты игроков, у разведданных координаты замаскированы. Аукцион.
- [ ] Наведение на лот даёт подсказку с ценой и продавцом.

## 4. Ноутбук

- [ ] Три вкладки: `СЛЕД`, `СУМКА`, `ТОРГ`.
- [ ] `TRACE` печатает позывной в поле и выдаёт результат под кнопками.
- [ ] `WIPE` в два нажатия, второе подтверждает.
- [ ] `INTEL`: строки не наезжают, устаревшая точка помечена.
- [ ] `СУМКА`: 36 слотов + хотбар, кнопка снимка.
- [ ] `ТОРГ`: слот, ползунок цены, продажа предмета и разведданных.

## 5. Механики

- [ ] Шум: скажите в чат несколько раз — полоса растёт, потом сама гаснет (−2 каждые 20 тиков).
- [ ] Шум: панель → `ШУМ 100`, затем TRACE по вам с другого клиента — луч должен быть уже.
- [ ] Пеленг: два луча дают точку с погрешностью.
- [ ] ЭМИ: панель → `ЭМИ`, телефон гаснет, меню закрывается, стойки перезагружаются, шум обнуляется.
- [ ] Флуд: панель → `ФЛУД`, экран забивается картинками.
- [ ] Рынок: покупка списывает крипту, лот появляется в инвентаре.
- [ ] Дедлайн: панель → `ФИНАЛ ЧЕРЕЗ 60С`, боссбар переключается на финал.
- [ ] Конец матча: победитель в чате, маяки, бункеры и схроны убраны, мир без дыр.

## 6. Что делать, если сломалось

1. Скопировать из `latest.log` строки вокруг ошибки — по ним видно, какой класс и какая строка.
2. Если ошибка в момент старта матча — приложить вывод `/bc status` и строки `BlackChannel: база ...`.
3. Если что-то не рисуется — указать вкладку и масштаб интерфейса (в настройках игры), на 1× и 3× вид разный.
