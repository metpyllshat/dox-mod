# dox-mod

Сборка тех-сервера и мод радиоразведки.

Игровой мод лежит в [`blackchannel`](blackchannel/README.md): телефон, ноутбук, dox по радиоотметке, деанон, ложный вызов, флуд, радар, жучки и защита. ЭМИ из Ballistix и EW гасит терминалы. Настоящие IP мод не читает.

Идеи и план развития мини-игры — в [`docs/vision`](docs/vision/00-index.md).
